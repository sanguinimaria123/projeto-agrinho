# projeto-agrinho
 Agro Forte: Futuro Sustentável
 Sobre o projeto

Este projeto foi desenvolvido como parte do concurso Agrinho 2026, com o tema “Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”.

O objetivo do site é apresentar, de forma interativa e educativa, os diferentes tipos de produção agrícola (convencional, orgânica e tecnológica), mostrando suas características, impactos e a importância de buscar um equilíbrio entre produtividade e sustentabilidade.

O site foi desenvolvido utilizando HTML, CSS e JavaScript, com foco em interatividade, organização visual e experiência do usuário.

 Ideia do projeto

A ideia surgiu a partir da reflexão de que o campo e a cidade estão conectados, e que as escolhas na produção de alimentos impactam diretamente o meio ambiente e a sociedade.

Por isso, o site foi dividido em três partes principais:

Explicação dos tipos de produção
Simulador interativo
Visualização de dados e resultado final

Além disso, foram adicionadas funcionalidades extras para melhorar a navegação e tornar o site mais moderno.

 Tecnologias utilizadas
 
HTML → estrutura do site
CSS → estilização, layout e animações
JavaScript → interatividade e lógica do simulador

 Processo de desenvolvimento

Primeiramente, foi criada a estrutura do site em HTML, organizando as seções como menu, explicação, simulador, gráfico e resultado.

Depois, foi aplicado o CSS para melhorar a aparência visual, utilizando cores em degradê em tons de verde para representar a natureza e o tema do projeto. Também foram adicionadas animações, efeitos de hover e organização dos elementos na tela.

Na parte do JavaScript, foi desenvolvido um simulador interativo onde o usuário pode escolher diferentes práticas agrícolas e observar como essas escolhas afetam o nível de sustentabilidade.

Também foi implementado um gráfico que mostra a evolução das decisões ao longo do tempo.

Por fim, foram criadas páginas adicionais para cada tipo de produção (convencional, orgânica e tecnológica), com textos explicativos mais detalhados.

 Como utilizar o site
 Menu de navegação

Na parte superior do site, há um menu fixo que permite navegar entre as seções:

Produção
Simulador
Dados
Resultado
 Cards interativos

Na seção de produção, existem três cards:

Convencional
Orgânica
Tecnológica

Ao clicar em cada um, o usuário é direcionado para uma página com explicações mais detalhadas sobre aquele tipo de produção.

 Simulador

O simulador permite que o usuário escolha práticas agrícolas.

Selecione uma opção no campo disponível
Clique em “Adicionar decisão”
Repita o processo quantas vezes quiser

Cada escolha influencia o nível de sustentabilidade, permitindo observar diferentes cenários.

Também existe o botão “Reiniciar”, que limpa a simulação.

 Gráfico

O gráfico exibe visualmente as decisões tomadas no simulador.

Ele mostra a evolução da sustentabilidade ao longo do tempo, ajudando a entender o impacto de cada escolha.

 Resultado

Ao final, o site apresenta um resultado baseado nas decisões tomadas, incentivando a reflexão sobre práticas mais sustentáveis.

Quiz

Um pequeno quiz foi adicionado para ampliar ainda mais os conhecimentos do usuário sobre a sustentabilidade do solo.

🌙 Botão de contraste (modo escuro)

O site possui um botão de modo escuro 🌙.

Ao clicar, o fundo da página fica escuro e o texto claro, melhorando a leitura e proporcionando uma experiência mais confortável.

Através da tecnologia, da conscientização e de boas práticas, podemos construir um futuro mais sustentável.
